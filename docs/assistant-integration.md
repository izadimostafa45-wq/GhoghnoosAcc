# اتصال دستیار هوشمند ققنوس

## وضعیت فعلی

- `POST /api/accounting/assistant/invoice-drafts` پیش‌نویس فاکتور فروش یا خرید را می‌سازد؛ ثبت نهایی و سند حسابداری ایجاد نمی‌کند.
- این مسیر به ورود کاربر و مجوز `TenantWrite` نیاز دارد و فقط طرف حساب فعال همان شرکت را می‌پذیرد.
- `POST /api/assistant/chat` برای کاربر واردشده پاسخ متنی تولید می‌کند. این مسیر به‌تنهایی اتصال خارجی ChatGPT یا مجوز ساخت فاکتور را فراهم نمی‌کند.
- فایل `docs/chatgpt-action-openapi.template.yaml` فقط قالب اولیه Action است؛ **قابل استفاده در ChatGPT نیست** تا وقتی که HTTPS عمومی و احراز هویت OAuth/API واقعی پیاده‌سازی و آزمایش شوند.
- کلید سرویس مدل فقط باید در تنظیمات امن سرور ذخیره شود؛ هرگز آن را در مخزن، کد سمت مرورگر یا پیام‌ها قرار ندهید.

## تنظیمات چت مدل

تنظیمات از پیکربندی ASP.NET Core خوانده می‌شوند:

- `OpenAI:ApiKey`: کلید محرمانه سرویس مدل
- `OpenAI:BaseUrl`: نشانی API سازگار با OpenAI
- `OpenAI:Model`: نام مدل در سرویس انتخاب‌شده

این پروژه در حال حاضر مقدار پیش‌فرضی برای سرویس و مدل دارد؛ پیش از استقرار باید سازگاری آن‌ها با ارائه‌دهنده واقعی تأیید شود. مقادیر محرمانه را با متغیرهای محیطی یا Secret Manager تنظیم کنید، نه در فایل‌های قابل commit.

## مراحل لازم برای اتصال واقعی ChatGPT

1. برنامه روی یک میزبان قابل دسترس با HTTPS مستقر شود؛ تونل موقت فقط برای آزمایش اتصال شبکه است و استقرار پایدار محسوب نمی‌شود.
2. روش احراز هویت مناسب برای اتصال خارجی (ترجیحاً OAuth یا توکن‌های کوتاه‌عمر با دامنه دسترسی محدود) طراحی و پیاده‌سازی شود؛ کوکی ورود مرورگر به‌تنهایی برای اتصال بیرونی کافی نیست.
3. مجوز شرکت فعال، عضویت کاربر و نقش نوشتن در سمت سرور بررسی شود. شناسه شرکت از ورودی مدل یا درخواست بدون اعتبارسنجی پذیرفته نشود.
4. عملیات ساخت پیش‌نویس از ثبت نهایی جدا بماند و قبل از هر ثبت مالی، تأیید کاربر در رابط برنامه گرفته شود.
5. آزمون‌های مجوز، جداسازی شرکت‌ها، اعتبارسنجی مبلغ، خطاهای سرویس و ثبت رویدادهای امنیتی اجرا شوند.

تا زمانی که استقرار HTTPS و احراز هویت اتصال خارجی انجام نشده، این قابلیت را اتصال فعال ChatGPT تلقی نکنید. هیچ endpoint را به‌صورت ناشناس یا با دور زدن ورود برنامه منتشر نکنید.
